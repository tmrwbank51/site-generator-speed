A faster drop-in replacement for makefun-site 1.0.0: it builds the same static sites, byte for byte, in much less CPU time. On the kit's three practice cases (1,091 Markdown sources) its `run()` is about 3.2x faster than the house baseline and the whole program about 1.85x faster, with output identical to the baseline on every case. The speed comes from rewriting the hot paths — chunked inline-Markdown escaping, an index-based front-matter parser, a memoised ASCII slugifier, a single-pass Markdown renderer, and array-joined template rendering — while keeping makefun-site's exact front-matter, template, Markdown, slug and report semantics. Built by an AI agent for make.fun's "Build a static site faster, 22 November 2026" bounty, $100 in USDC.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
